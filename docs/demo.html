ai-delegates 派工流程ai-delegates: how a request is delegated

選「在哪個 CLI 工作」和每個角色要用哪個 AI,按播放看一個需求怎麼被拆給主控與副手。右邊是每一步實際執行的指令與回應。改檔、跑測試永遠由你正在用的那個 CLI 做,外部 AI 只有唯讀。 Pick where you work and which AI handles each role, then press play to see how one request is split between the lead and the helpers. The terminal on the right shows the command and reply for each step. Edits and tests are always done by the CLI you are working in; outside AIs are read-only.
